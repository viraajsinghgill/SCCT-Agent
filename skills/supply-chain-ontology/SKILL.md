# Supply Chain Ontology Authoring & Governance Skill

## Overview
This skill provides standardized methodologies to author, validate, and evolve enterprise supply chain ontologies and Snowflake Cortex Analyst semantic models. It maps core multi-tier supply chain entities (`Tier 3 Raw Suppliers` -> `Tier 2 Fabric Mills` -> `Tier 1 Assembly Factories` -> `Purchase Orders` -> `Shipments` -> `Distribution Centers` -> `Omnichannel Stores` -> `Returns`) and binds them to governed semantic measures.

## Key Instructions for Agents
1. **Entity & Relationship Integrity**:
   - Ensure all entity classes specify explicit primary keys, foreign key relationships, and cardinality (`1:N`, `N:M`).
   - Validate that Multi-Tier Bills of Materials (BOM) maintain lineage from base commodities to finished product SKUs.
2. **Cortex Analyst Semantic Model Mapping**:
   - Model measures with canonical aggregation rules (`SUM`, `RATIO`, `AVERAGE`).
   - Define business-facing synonyms for all dimensions and measures to maximize text-to-SQL natural language coverage.
   - Include verified golden SQL queries for high-frequency enterprise questions.
3. **Governance & Anti-Hallucination**:
   - Queries generated by conversational agents must strictly target Gold Semantic Views rather than uncurated Bronze raw tables.
